# @evanion/astro-widget

**Move layout decisions out of your views and into a testable logic layer.**

Views that change based on feature flags, user roles, or record state often become cluttered with conditional branching. `@evanion/astro-widget` solves this by moving that logic into a plain function that returns a list of items. The view then renders this list with no branches, while the logic remains testable without rendering a single component. This list can be generated by your code or sourced from a CMS. During the build or request, `@evanion/astro-widget` renders the result on the server, so the browser receives HTML with no JavaScript for the layout.

To ensure your logic or CMS provides the correct data, `validateItems` checks the list before the page renders:

<!-- #region validate -->

```ts @import.meta.vitest
import { validateItems } from '@evanion/astro-widget';

const items = [
  {
    id: 'header',
    type: 'listing-header',
    props: { title: 'Brass: Birmingham' },
  },
  { id: 'price', type: 'price-box', props: {} },
  { id: 'questions', type: 'answer-wall', props: {} },
];

const required = { 'listing-header': ['title'], 'price-box': ['price'] };
const problems = validateItems(
  items,
  ['listing-header', 'price-box'],
  required,
);

problems; // -> [{ index: 1, id: 'price', type: 'price-box', message: 'missing field price' }, { index: 2, id: 'questions', type: 'answer-wall', message: 'unknown widget type' }]
```

## Capabilities of @evanion/astro-widget

`@evanion/astro-widget` allows you to build structured, content-heavy pages without the overhead of client-side layout engines:

- **Zero Layout JS**: No client-side JavaScript is required to decide which component renders an item.
- **Tiny Bundles**: By keeping layout logic on the server, the amount of code shipped to the user is reduced.
- **CI Safety**: Use `validateItems` as a "loud gate" in your CI pipeline to catch bad items, from your logic or a CMS, before they reach production.
- **Universal Data**: Share layouts between a static Astro site and a dynamic React app by using the same item array as `@evanion/react-widget`.

## Requirements and Installation

`@evanion/astro-widget` is ESM only and requires Node 22.12 or newer. It requires Astro `^7.3.4` as a peer dependency and includes `@evanion/widget` as a pinned, re-exported dependency.

```bash
npm install @evanion/astro-widget
```
