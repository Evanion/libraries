## Before you install compose

- React 18 or 19, the only dependency the package has.
- An ESM project, or a Node whose `require()` loads ES modules. An older
  runtime's `require()` fails with `ERR_REQUIRE_ESM`.
- Node 20 or newer.
- TypeScript 5.0 or newer for the per-entry checks, because the published types
  use a `const` type parameter. The component runs without TypeScript.

## Install compose

Pick the line for your package manager.

```bash
npm install @evanion/compose
```

```bash
yarn add @evanion/compose
```

```bash
pnpm add @evanion/compose
```

## Compose the shop's providers

`ComposeProvider` takes two props: `providers`, the array, and `children`, what
the array wraps. Baize, the board game shop these examples are set in, holds
three providers at its root and renders them around the page it is given:

```tsx twoslash file=libs/compose/README.md region=first-shop

```

`CartProvider` and `CurrencyProvider` go in as bare components, because neither
declares a prop beyond `children`. `ThemeProvider` needs a `theme`, so
`provider(ThemeProvider, { theme: 'dark' })` pairs it with its props. No entry
passes `children`: `ComposeProvider` fills each one with the next entry down,
and the last entry gets `Shop`'s own children.

`markup` is the HTML React wrote for `Shop`. The cart's `div` is outermost and
the page is innermost, which is the array read from the top. If your own root
renders its page inside every provider in that order, compose is working in your
project.

## Move a compose entry and watch the tree move

The boxes below are the elements `ComposeProvider` returned for the array shown
with them. Move an entry up and its box moves outward; move it down and the boxes it
contained close over it.

<ComposeSpecimen />

The control renders the published `ComposeProvider`, so what reorders is a real
provider tree. Each move remounts everything inside the outermost box that changed
position, because React reconciles by position. In an app a remount drops the state under it, so
keep your array fixed and let a provider handle its own conditional case.
