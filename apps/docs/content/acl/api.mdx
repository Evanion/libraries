# API reference

<WorkshopNotice slug="acl" />

Every export of `@evanion/acl`, one heading each. Node 20 or newer, ESM only.
The React provider and hooks are [`@evanion/react-acl`](/react-acl/api).

## `hydratePolicy`

Builds an evaluator over a matrix document.

```ts signature
function hydratePolicy<
  Sub = Subject,
  R = AnyObjects,
  Keys extends string = string,
>(matrix: Matrix, options?: AccessOptions): Access<Sub, R, Keys>;
```

It copies the document, freezes and validates the copy, and throws on an unknown
key. All three parameters default to the open forms JSON carries.

## `parseMatrix`

`hydratePolicy` with `closed: true`, for a document another service published.

```ts signature
function parseMatrix<
  Sub = Subject,
  R = AnyObjects,
  Keys extends string = string,
>(matrix: Matrix, options?: AccessOptions): Access<Sub, R, Keys>;
```

An unknown object kind or action answers `unknown-action` and nothing throws.
`Keys` is the union the consumer expects, unchecked against the document. See
[Adopting a foreign matrix](/acl/matrix#adopting-a-foreign-matrix).

## `policy`

The typed builder, one `.for()` per object kind. See
[Typed authoring](/acl/authoring).

```ts signature
function policy<
  Sub,
  Objects,
  Vocabs extends Partial<Record<keyof Objects, string>> = Record<never, never>,
>(
  options?: PolicyOptions,
): Policy<Sub, Objects, Vocabs, Record<never, never>, never>;
```

`Objects` maps each kind to its row type and `Vocabs` maps a kind to the actions
it answers for; a kind `Vocabs` omits takes `Action`.

## `Policy`

```ts signature
interface Policy<
  Sub,
  Objects,
  Vocabs extends Partial<Record<keyof Objects, string>>,
  R,
  Keys extends string = string,
> {
  for<K extends keyof Objects & string, Act extends string = string>(
    key: K,
    build: (
      p: Actions<Sub, Objects[K], never, VocabularyOf<Vocabs, K>>,
    ) => Actions<Sub, Objects[K], Act, VocabularyOf<Vocabs, K>> | void,
  ): Policy<
    Sub,
    Objects,
    Vocabs,
    R & Record<K, Objects[K]>,
    Keys | PermissionKeys<K, Act>
  >;
  readonly matrix: Readonly<Matrix>;
  build(options?: AccessOptions): Access<Sub, R, Keys>;
}
```

`for` takes no type arguments, reading the object type out of `Objects`, the
vocabulary out of `Vocabs` and `Act` off the chain its block returns. `matrix`
flattens the blocks without building one.

## `PolicyOptions`

```ts signature
type PolicyOptions = Pick<Matrix, 'version' | 'schema'>;
```

Both are document fields, so they land in the flattened JSON.

## `AccessOptions`

```ts signature
interface AccessOptions {
  version?: string | number;
  closed?: boolean;
  fetchedAt?: Instant;
  maxStale?: number;
}
```

`version` overrides the document's. `closed` fails closed on an unknown key.
`fetchedAt` is when this holder last validated. A holder that supplies it
obliges the document to state `maxStale`, which here is a local ceiling `min`-ed
with the document's.

## `Access`

The evaluator over one frozen document.

```ts signature
interface Access<Sub = Subject, R = AnyObjects, Keys extends string = string> {
  readonly matrix: Readonly<Matrix>;
  readonly version: string | number | undefined;
  readonly schema: MatrixSchema | undefined;

  can(subject, key, action, object?, now?): Decision;
  canMany(subject, key, action, objects, now?): Decision[];
  canFields(subject, key, action, object, axis, proposed?, now?): FieldDecision;
  capabilities(subject, now?): Record<Keys, Decision>;
  authorize(subject, options?: { now?: Instant }): Authorized<R, Keys>;
  object(key): BoundKind<Sub, R[K], ActionOf<Keys, K>>;
  readsObject(key, action): boolean;
}
```

`canMany` settles one clock for the whole list. `readsObject` says whether the
permission needs the row before it can decide.

Every object parameter takes a partial: a projection is the
[`unevaluable`](/acl/refusals#when-the-answer-is-unevaluable) case. An absent
`subject.*` path is a definite miss.

## `Authorized`

What `authorize(subject)` returns.

```ts signature
interface Authorized<R = AnyObjects, Keys extends string = string> {
  can<K extends keyof R & string>(
    key: K,
    action: ActionOf<Keys, K>,
    object?: Partial<R[K]>,
  ): Decision;
  canMany<K extends keyof R & string>(
    key: K,
    action: ActionOf<Keys, K>,
    objects: readonly Partial<R[K]>[],
  ): Decision[];
  canFields<K extends keyof R & string>(
    key: K,
    action: ActionOf<Keys, K>,
    object: Partial<R[K]>,
    axis: 'read' | 'write',
    proposed?: Partial<R[K]>,
  ): FieldDecision;
  capabilities(): Record<Keys, Decision>;
}
```

None of `matrix`, `version`, `schema` or `readsObject` is a fact about one
subject, so none is here.

## `BoundKind`

What `object(key)` returns.

```ts signature
interface BoundKind<Sub, Obj, Act extends string = string> {
  can(
    subject: Sub,
    action: Act,
    object?: Partial<Obj>,
    now?: Instant,
  ): Decision;
  canMany(
    subject: Sub,
    action: Act,
    objects: readonly Partial<Obj>[],
    now?: Instant,
  ): Decision[];
  canFields(
    subject: Sub,
    action: Act,
    object: Partial<Obj>,
    axis: 'read' | 'write',
    proposed?: Partial<Obj>,
    now?: Instant,
  ): FieldDecision;
  readsObject(action: Act): boolean;
}
```

`authorize` binds the other axis; the two compose.

## `KeysOf`

```ts signature
type KeysOf<A> = A extends Access<never, never, infer Keys> ? Keys : never;
```

The permission keys an `Access` carries, lifted out of its type. A producer
exports `KeysOf<typeof access>` for a consumer compiled against its source.

## `ActionOf`

```ts signature
type ActionOf<Keys extends string, K extends string> = [Keys] extends [never]
  ? string
  : string extends Keys
    ? string
    : [Extract<Keys, `${K}.${string}`>] extends [never]
      ? string
      : Keys extends `${K}.${infer Act}`
        ? Act
        : never;
```

The action half of the keys one object kind holds, checked against every query's
action parameter. Open, empty and unmatched key unions answer `string`.

## `CRUD_ACTIONS`

```ts signature
const CRUD_ACTIONS: readonly ['create', 'read', 'update', 'delete'];
```

The one declaration of the four default verbs, which `Action` is read off. Pass
it to `allowEach`.

## `pickAllowedFields`

The subset of a proposed write the decision marked `allowed`. It throws
`ActionNotAllowedError` on a refused action. See
[the write path](/acl/fields#writing).

```ts signature
function pickAllowedFields<T extends Record<string, unknown>>(
  decision: FieldDecision,
  proposed: T,
): Partial<T>;
```

## `serialize`

```ts signature
function serialize<Sub, R, Keys>(
  access: Access<Sub, R, Keys>,
  mode: 'full',
): Matrix;
function serialize<Sub, R, Keys>(
  access: Access<Sub, R, Keys>,
  mode: 'reduced',
  options?: SerializeOptions<Keys>,
): Matrix;
```

`full` hands back `access.matrix`. `reduced` keeps each permission marked
`visibility: 'public'` whole, strips the marking, and adds the `schema` entries
for the kinds they name. See
[Many services](/acl/federation#publishing-the-rules-to-a-consumer).

## `SerializeMode`

```ts signature
type SerializeMode = 'full' | 'reduced';
```

## `SerializeOptions`

```ts signature
interface SerializeOptions<Keys extends string = string> {
  readonly vetoable?: readonly Keys[];
}
```

A listed key the reduction would drop raises `UnpublishedVetoableError`. A key
the document never held is refused earlier, by the compiler, where the policy
was authored with the builder. `DenyOverlayOptions` takes no such parameter: it
carries a `Matrix`, and the team writing an overlay holds that document as JSON
and no types.

## `federatedPolicies`

One `Access` per origin, composed with no document merged. See
[Many services](/acl/federation).

```ts signature
function federatedPolicies(
  policies: Readonly<Record<string, Access>>,
): FederatedAccess;
```

## `FederatedAccess`

```ts signature
interface FederatedAccess {
  can(
    subject: Subject,
    key: string,
    action: string,
    object?: Record<string, unknown>,
    now?: Instant,
  ): Decision;
  capabilities(subject: Subject, now?: Instant): Record<string, Decision>;
  get(origin: string): Access | undefined;
}
```

`can` routes to the origin holding `` `${object}.${action}` ``; a key no member
holds answers `unknown-action`. `capabilities` settles one instant for all.

## `applyDenyOverlay`

Appends another team's deny rules to the keys this document opens for veto. See
[Many services](/acl/federation#a-cross-cutting-deny-is-an-overlay-the-owner-applies).

```ts signature
function applyDenyOverlay(
  matrix: Matrix,
  overlay: DenyOverlay,
  options: DenyOverlayOptions,
): Matrix;
```

## `DenyOverlay`

```ts signature
type DenyOverlay = Readonly<Record<string, readonly Rule[]>>;
```

A `Rule` spells no allow and no field rule, so an overlay only subtracts.

## `DenyOverlayOptions`

```ts signature
interface DenyOverlayOptions {
  readonly vetoable: readonly string[];
}
```

Listing a key obliges the matrix to declare that key's object kind in
`schema.objects`.

## `Matrix`

A JSON envelope over a flat list of permissions. See
[The matrix document](/acl/matrix).

```ts signature
interface Matrix {
  readonly version?: string | number;
  readonly maxStale?: number; // how long a holder may keep deciding on it
  readonly schema?: MatrixSchema;
  readonly permissions: readonly Permission[];
}
```

## `Permission`

```ts signature
interface Permission {
  key: string; // exactly `${object}.${action}`
  object: ObjectKey;
  action: string; // whatever the producer wrote
  rules?: readonly Rule[]; // allows, OR-ed
  denyRules?: readonly Rule[]; // denies, OR-ed; a matched deny wins
  fields?: FieldRules;
  visibility?: 'public' | 'internal'; // absent is internal
}
```

## `Rule`

```ts signature
interface Rule {
  id?: string; // what a decision reports as `rule`; defaults to `#0`, `#1`, …
  when?: readonly Condition[]; // AND-ed
}
```

## `Condition`

[The matrix document](/acl/matrix#conditions) has the operator table.

```ts signature
type Condition =
  | { field: 'now'; op: 'before' | 'after'; value: Instant }
  | {
      field: string;
      op: 'eq' | 'ne' | 'in' | 'not-in' | 'contains';
      path?: string; // the `eq`/`ne` form only
      value?: unknown;
    };
```

## `FieldRules`

```ts signature
interface FieldRules {
  fields?: readonly string[]; // ['*', '!status'] or ['body', 'title']
  [field: string]: readonly string[] | FieldConfig | undefined;
}
```

Every other key is a field name carrying a write-axis config, so a field named
`fields` cannot be configured.

## `FieldConfig`

```ts signature
type FieldConfig =
  | { targets: readonly unknown[] }
  | { transitions: Record<string, readonly unknown[]> };
```

`targets` allow-lists the proposed value; `transitions` is a state machine over
the current one. See [Fields](/acl/fields).

## `MatrixSchema`

```ts signature
interface MatrixSchema {
  readonly subject?: ObjectSchema;
  readonly objects?: Readonly<Record<ObjectKey, ObjectSchema>>;
}
```

Optional for a producer, binding where present, per kind: a kind `objects` omits
is unchecked.

## `ObjectSchema`

```ts signature
interface ObjectSchema {
  readonly fields?: Readonly<Record<string, FieldType>>;
  readonly relations?: Readonly<Record<string, ObjectKey>>;
}
```

`relations` names the kinds one kind points at, one hop. No condition compares
one.

## `FieldType`

```ts signature
type FieldType =
  | BaseFieldType
  | `${BaseFieldType}[]`
  | `${BaseFieldType}?`
  | `${BaseFieldType}[]?`;
```

`?` marks a field that may be absent. A flat string any language emits by
reflection.

## `BaseFieldType`

```ts signature
type BaseFieldType = 'string' | 'number' | 'boolean' | 'instant';
```

## `Instant`

```ts signature
type Instant = string | number | Date;
```

A string parses as ISO 8601, a number as epoch milliseconds; both survive JSON.

## `Decision`

```ts signature
interface Decision {
  key: string;
  allowed: boolean;
  reason: Reason;
  rule?: string;
  missing?: readonly string[];
}
```

`allowed` is the gate; the other three are output only.
[Decisions](/acl/decisions) says which reason carries which.

## `Reason`

```ts signature
type Reason =
  | 'allow'
  | 'no-rule-matched'
  | 'denied'
  | 'unknown-action'
  | 'unevaluable'
  | 'unusable-clock'
  | 'stale-contract';
```

## `FieldDecision`

```ts signature
interface FieldDecision {
  allowed: boolean; // the action is allowed AND every decided field is
  action: Decision; // the action alone
  fields: Record<string, FieldState>;
  reasons: Record<string, FieldReason>;
}
```

## `FieldState`

```ts signature
type FieldState = 'allowed' | 'denied' | 'unevaluable';
```

Compare against `'allowed'`; comparing against `'denied'` treats an unevaluable
field as writable. See
[Pitfalls](/acl/pitfalls#never-hand-filter-the-field-map).

## `FieldReason`

```ts signature
type FieldReason =
  | 'allow'
  | 'not-listed'
  | 'targets-failed'
  | 'transition-failed'
  | 'missing-field'
  | 'proposed-required';
```

## `EvaluationContext`

```ts signature
interface EvaluationContext {
  subject: Record<string, unknown>;
  object?: Record<string, unknown>;
  now?: Instant;
}
```

The entry points assemble this; `now` settles to one epoch per call.

## `Actions`

The block parameter `.for()` hands you. `Vocab` is what this kind may declare,
`Act` what this chain declared, and only `Act` reaches the permission keys.

```ts signature
interface Actions<
  Sub,
  Obj,
  Act extends string = string,
  Vocab extends string = string,
> extends Ops<Sub, Obj> {
  allow<A extends Vocab>(
    action: A,
    ...conditions: Cond[]
  ): Actions<Sub, Obj, Act | A, Vocab>;
  deny<A extends Vocab>(
    action: A,
    ...conditions: Cond[]
  ): Actions<Sub, Obj, Act | A, Vocab>;
  allowEach<A extends Vocab>(
    actions: readonly A[],
    ...conditions: Cond[]
  ): Actions<Sub, Obj, Act | A, Vocab>;
  denyEach<A extends Vocab>(
    actions: readonly A[],
    ...conditions: Cond[]
  ): Actions<Sub, Obj, Act | A, Vocab>;
  fields(rules: readonly string[] | FieldRules): Actions<Sub, Obj, Act, Vocab>;
  visibility(visibility: Visibility): Actions<Sub, Obj, Act, Vocab>;
}
```

`allowEach` and `denyEach` write one rule across several actions, one ordinary
permission each. `fields` and `visibility` mark the action last declared and
raise `AclConfigError` after a batch.

## `Action`

```ts signature
type Action = (typeof CRUD_ACTIONS)[number];
```

The vocabulary a kind gets when `Vocabs` names none. No wildcard member sits
here, and `docs/specs/2026-09-17-acl-wildcard-action.md` records why.

## `VocabularyOf`

```ts signature
type VocabularyOf<Vocabs, K extends string> = K extends keyof Vocabs
  ? Vocabs[K] extends string
    ? Vocabs[K]
    : Action
  : Action;
```

What one kind's block may declare from. `string` there opens the kind to any
action.

## `Visibility`

```ts signature
type Visibility = NonNullable<Permission['visibility']>;
```

The marking `p.visibility()` writes and `serialize(access, 'reduced')` reads.

## `PermissionKeys`

```ts signature
type PermissionKeys<K extends string, Act extends string> = string extends Act
  ? string
  : `${K}.${Act}`;
```

The keys one block contributes. An `Act` the compiler reads as `string`
contributes `string`, widening the document's whole key union.

## `Ops`

The condition helpers, bound to the subject and object types.

```ts signature
interface Ops<Sub, Obj> {
  eq<A extends string, B>(
    field: Valid<A, Sub, Obj>,
    operand: Operand<B, Sub, Obj>,
  ): Cond;
  ne<A extends string, B>(
    field: Valid<A, Sub, Obj>,
    operand: Operand<B, Sub, Obj>,
  ): Cond;
  in<A extends string>(
    field: Valid<A, Sub, Obj>,
    values: readonly unknown[],
  ): Cond;
  notIn<A extends string>(
    field: Valid<A, Sub, Obj>,
    values: readonly unknown[],
  ): Cond;
  contains<A extends string>(field: Valid<A, Sub, Obj>, value: unknown): Cond;
  before(field: 'now', instant: Instant): Cond;
  after(field: 'now', instant: Instant): Cond;
  and(...conditions: Cond[]): Cond;
  or(...conditions: Cond[]): Cond;
  readonly always: Cond;
}
```

`not-in` is not an identifier, so the helper is `notIn`.

## `Cond`

```ts signature
interface Cond {
  readonly node: Node;
}
```

An opaque condition tree. `build()` flattens it to one rule per `or` branch.

## `Operand`

```ts signature
type Operand<B, Sub, Obj> = B extends
  `subject.${string}` | `object.${string}` | 'now'
  ? Valid<B & string, Sub, Obj>
  : B;
```

A comparand shaped like a namespaced path is checked as one; any other string
is a literal.

## `Paths`

```ts signature
type Paths<T, P extends string> = {
  [K in keyof T & string]: `${P}.${K}`;
}[keyof T & string];
```

## `Valid`

```ts signature
type Valid<S extends string, Sub, Obj> = S extends
  Paths<Sub, 'subject'> | Paths<Obj, 'object'> | 'now'
  ? S
  : `unknown path '${S}' on this resource`;
```

The failure branch is the parameter type, so the compiler names the bad path.

## What is not exported

`decide`, `decideFields` and `evaluateCondition`. Each answers a fragment and
trusts its caller for the rest.
