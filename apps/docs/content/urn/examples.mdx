# Examples

A shop's services mostly read URNs that another service wrote. `parse`,
`isValidFormat` and `equals` do the reading, and `stringify` with `encodeNss`
does the writing.

## One URN class per namespace

The shop names games and orders, so it has two namespace classes: `GameURN`,
from Getting started, and an `OrderURN` beside it. No call site names a
namespace, and `belongsToNamespace` picks one kind out of a mixed list:


`belongsToNamespace` returns `false` for `'hive'`, which is not a URN, so a
filter over untrusted input needs no `try` block.

Each class strips only its own NID on `parse`. A foreign NID stays at the front
of the `nss`, a foreign scheme keeps the whole identifier, and the case a part
was written in comes back unchanged:

## Mint a batch of game URNs

`stringify` throws an `InvalidError` on a part that breaks its grammar. A job
minting URNs for a batch of slugs catches per slug, so one bad slug skips and
the rest are minted:

```ts twoslash file=libs/urn/README.md region=batch-mint

```

The NSS grammar is RFC 3986's `pchar`: letters, digits, `-._~!$&'()*+,;=:@` and
percent-triplets, with `/` allowed after the first character. A space is outside
it. The NID is stricter: letters, digits and interior hyphens, 2 to 32
characters.

## Put a game title into a URN

A title a person typed carries spaces and punctuation. `encodeNss`
percent-encodes everything outside RFC 3986's `unreserved` set, and `decodeNss`
reverses it. `stringify` and `parse` do neither:

```ts twoslash file=libs/urn/README.md region=nss-encoding

```

`encodeNss` also encodes the `:`, which the NSS grammar allows, so its output is
safe in any position of an NSS.

## Carry a URN in a URL path

`encodeURIComponent` makes a whole URN safe as one path segment, where `:` and
`%` mean something to a router. `encodeNss` makes a string safe as an NSS. A URN
built from a title needs both, NSS first:

```ts twoslash file=libs/urn/README.md region=url-segment

```

The `%3A` inside the NSS becomes `%253A` in the path, and one
`decodeURIComponent` turns it back. A second decode would turn `%3A` into `:`
and `%20` into a space, and `parse` throws on the space.

## Compare URNs from two sources

Two services can write the same URN differently. RFC 8141 §3.1 folds the case of
the scheme, of the NID and of a percent-triplet's hex digits, and nothing else:

```ts twoslash file=libs/urn/README.md region=equality

```

The third and fourth calls are where `===` on lowercased strings goes wrong:
`equals` never decodes `%3A`, and the NSS keeps its case. Call `equals` wherever
URNs arrive from more than one producer.
