# Welcome to Evanion Docs

Welcome to the comprehensive documentation for Evanion's open-source libraries. Here you'll find guides, API references, examples, and interactive playgrounds for all our libraries.

## Available Libraries

### [Compose](/compose)

Flattens nested React providers into a single readable array, with each
provider's props checked against its component.

### [React Widget](/widget)

A powerful and flexible React widget library for building interactive components.

### [URN Library](/urn)

A URN Library that makes it easier to work with more meaningful identifiers. The API is inspired by, and designed to be as simple as the JSON class.
