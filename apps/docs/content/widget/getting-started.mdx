## Before you install the widget core

- Node 20 or newer.
- An ECMAScript module (ESM) project. A CommonJS project needs Node 20.19,
  22.12 or newer, whose `require()` loads ES modules. An older `require()`
  fails with `ERR_REQUIRE_ESM`.

The package has no dependencies. If your project already depends on
`@evanion/react-widget` or `@evanion/astro-widget`, skip the install and import
the names below from that renderer. Each renderer pins `@evanion/widget`
exactly and re-exports every name this page uses.

## Install the widget core

Pick the line for your package manager.

```bash
npm install @evanion/widget
```

```bash
yarn add @evanion/widget
```

```bash
pnpm add @evanion/widget
```

## Check a widget item array with validateItems

Each item carries an `id`, the `type` of component that draws it, and that
component's `props`. In a file named `check.ts`:

1. Write the listing page as an array of `AnyWidgetItem`.
2. List the types your renderer has a component for.
3. Pass both to `validateItems`, importing both names from `@evanion/widget`.

```ts twoslash file=libs/widget/README.md region=unknown

```

To print the result, add `console.log(problems);` at the end and run
`npx tsx check.ts`, which runs a TypeScript file with no build step.

`problems` holds one `WidgetProblem`. The item at `index` 1, `tonight`, names
the type `featured-shelf`, which is not in `known`, so a renderer skips the
shelf. Change its `type` back to `shelf` and `validateItems`
returns `[]`.

Call `validateItems` wherever a payload enters your system, and throw or exit
non-zero when `problems` is not empty:

- in the webhook handler your content management system posts a save to
- in a continuous integration (CI) job over the payloads committed to the
  repository
- in the build script, before it writes the pages
- in a test over the fixtures your pages render

## Move a widget item and watch the renderer redraw the page

A renderer draws items in array order and nests `children` inside their parent,
so reordering the array reorders the page. The page below is Baize's
back-office dashboard, which `@evanion/react-widget` draws from two top-level
items:

- `week`, a `columns` item holding three `metric` items: games in, games sold
  and turnaround.
- `counter`, a `columns` item holding the `tables` board, which carries
  `meta: { span: 2 }`, and the `reprints` board.

<DataDemo />

Each item is printed under the page with move controls beside it. Move
`counter` above `week` and both boards move with it. Move `tables` past
`reprints` and the wide board changes sides, because `meta.span` belongs to the
item it sits on.
