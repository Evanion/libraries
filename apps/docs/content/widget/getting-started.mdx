## Before you install the widget core

- Node 20 or newer.
- An ESM project. A CommonJS project needs Node 20.19, 22.12 or newer, whose
  `require()` loads ES modules. An older `require()` fails with
  `ERR_REQUIRE_ESM`.

The package has no dependencies. A project that already has
`@evanion/react-widget` or `@evanion/astro-widget` skips the install below:
each renderer pins `@evanion/widget` exactly and re-exports every name this page
uses.

## Install the widget core

Pick the line for your package manager.

```bash
npm install @evanion/widget
```

```bash
yarn add @evanion/widget
```

```bash
pnpm add @evanion/widget
```

## Check a widget item array with validateItems

Each item carries an `id`, the `type` of component that draws it, and that
component's `props`. Write the listing page as an array of `AnyWidgetItem`,
list the types your renderer has a component for, and pass both to
`validateItems`. Import both names from `@evanion/widget`:

```ts twoslash file=libs/widget/README.md region=unknown

```

`problems` holds one `WidgetProblem`. The item at `index` 1, `tonight`, names
the type `featured-shelf`, which is not in `known`, so a renderer would leave
the shelf off the page. Change its `type` back to `shelf` and `validateItems`
returns `[]`.

No renderer calls `validateItems`. Call it wherever a payload enters your
system, and fail when `problems` is not empty:

- in the webhook handler your CMS posts a save to
- in a CI job over the payloads committed to the repository
- in the build script, before it writes the pages
- in a test over the fixtures your pages render

## Move a widget item and watch the page recompose

The page below is Baize's back-office counter, drawn by `@evanion/react-widget`
from seven items. The items are listed under it, with move controls beside each
one.

<DataDemo />

`week` holds three figures and `counter` holds two boards, as `children`. Move
`counter` above `week` and both boards move with it. Move `tables` past
`reprints` and the wide side of the counter changes sides, because `meta.span`
belongs to the item it sits on.
