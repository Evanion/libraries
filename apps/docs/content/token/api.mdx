# API reference

`@evanion/token` exports `createToken`, the types it takes and returns, five
constants and three error classes, one heading each below. Node 20 or newer,
ESM only.

<ApiFilter />

## `createToken`

<!-- reference @evanion/token#createToken example=at-a-glance -->

The default `chunkSize` of 4 does not divide every `length`, so a `length` that
is not a multiple of 4 names its own `chunkSize`.

## `Token`

<!-- reference @evanion/token#Token example=instances -->

`Token` is the frozen object `createToken` returns.

| Member                             | What it is                                                 |
| ---------------------------------- | ---------------------------------------------------------- |
| `generate`                         | mints a code; never retries and never checks for collision |
| `validate`                         | reports whether a string is a well-formed code             |
| `dictionary`                       | the alphabet, as configured                                |
| `n`                                | the number of characters in the dictionary                 |
| `length`, `chunkSize`, `separator` | the shape, as configured                                   |
| `entropyBits`                      | `(length - 1) * log2(n)`, the random bits in one code      |

## `TokenOptions`

<!-- reference @evanion/token#TokenOptions example=spoken -->

| Option       | Default              | Constraint                                                                 |
| ------------ | -------------------- | -------------------------------------------------------------------------- |
| `length`     | `DEFAULT_LENGTH`     | an integer of at least 2, the check character included                     |
| `chunkSize`  | `DEFAULT_CHUNK_SIZE` | an integer of at least 1 that divides `length`                             |
| `separator`  | `DEFAULT_SEPARATOR`  | non-empty, and sharing no character with `dictionary`                      |
| `dictionary` | `DEFAULT_DICTIONARY` | the four constraints under [`InvalidAlphabetError`](#invalidalphabeterror) |

## `GenerateOptions`

<!-- reference @evanion/token#GenerateOptions example=prefix -->

`prefix` is not checked against the dictionary and is not part of the check
character.

## `GenerateResult`

<!-- reference @evanion/token#GenerateResult example=generate -->

`value` is `prefix`, `separator` and the chunked code. `body` is what to store
and index on.

## `ValidateResult`

<!-- reference @evanion/token#ValidateResult example=lookup -->

`validate` strips the separator and folds case before it checks, so `body` is
the same string whatever grouping or case the input used.

## `ValidToken`

<!-- reference @evanion/token#ValidToken -->

`ValidToken` is the `valid: true` half of `ValidateResult`.

## `InvalidToken`

<!-- reference @evanion/token#InvalidToken -->

`InvalidToken` is the `valid: false` half of `ValidateResult`.

## `ValidateFailureReason`

<!-- reference @evanion/token#ValidateFailureReason example=validate -->

`validate` checks in the order the union lists and reports the first failure. A
prefix is not part of a code: `validate` reads a leading `ORD-` as three more
characters, and its `o` is `outside-alphabet`.

## `TokenError`

<!-- reference @evanion/token#TokenError example=catch-both -->

A dictionary that fails one of Luhn's constraints, even size, no repeats and no
case pairs, throws `InvalidDictionaryError` from `@evanion/luhn`, which does not
extend `TokenError`. The example catches the two by name.

## `InvalidAlphabetError`

<!-- reference @evanion/token#InvalidAlphabetError example=alphabet-errors -->

| Property     | What it is                                                             |
| ------------ | ---------------------------------------------------------------------- |
| `reason`     | an `InvalidDictionaryReason`                                           |
| `dictionary` | the dictionary as supplied                                             |
| `offending`  | the characters named; empty for `non-uniform`, which is about the size |

| Constraint                      | Thrown by                                       |
| ------------------------------- | ----------------------------------------------- |
| no confusable characters        | `InvalidAlphabetError`, `reason: 'confusable'`  |
| lowercase                       | `InvalidAlphabetError`, `reason: 'unfolded'`    |
| `256 % n === 0`                 | `InvalidAlphabetError`, `reason: 'non-uniform'` |
| even size, no repeats, no pairs | `InvalidDictionaryError` from `@evanion/luhn`   |

## `InvalidDictionaryReason`

<!-- reference @evanion/token#InvalidDictionaryReason -->

| `reason`      | The dictionary                               |
| ------------- | -------------------------------------------- |
| `confusable`  | holds a character of `CONFUSABLE_CHARACTERS` |
| `unfolded`    | holds an uppercase character                 |
| `non-uniform` | has a size that does not divide 256          |

## `InvalidShapeError`

<!-- reference @evanion/token#InvalidShapeError example=shape-errors -->

| Property                           | What it is                               |
| ---------------------------------- | ---------------------------------------- |
| `reason`                           | an `InvalidShapeReason`                  |
| `length`, `chunkSize`, `separator` | all three as resolved, defaults included |

## `InvalidShapeReason`

<!-- reference @evanion/token#InvalidShapeReason -->

| `reason`                  | The shape                                        |
| ------------------------- | ------------------------------------------------ |
| `length`                  | `length` is not an integer, or is below 2        |
| `chunk-size`              | `chunkSize` is not an integer, or is below 1     |
| `chunk-size-indivisible`  | `chunkSize` does not divide `length`             |
| `separator-empty`         | `separator` is the empty string                  |
| `separator-in-dictionary` | `separator` shares a character with `dictionary` |

## `TokenShape`

<!-- reference @evanion/token#TokenShape -->

`InvalidShapeError` takes a `TokenShape` and copies its three fields onto
itself.
