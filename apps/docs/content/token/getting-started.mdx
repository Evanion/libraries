# Getting started

By the end of this page `createToken` mints a pickup code for your shop, and
`validate` refuses a misheard one before your order table is queried.

## Before you install token

- Node 20 or newer, or any browser. `generate` draws from
  `crypto.getRandomValues`, which both supply with no import and no polyfill.
- An ESM project. A CommonJS project needs Node 20.19, 22.12 or newer, whose
  `require()` loads ES modules. An older `require()` fails with
  `ERR_REQUIRE_ESM`.
- `@evanion/luhn`, which installs with the package and computes the check
  character.

## Install token

Pick the line for your package manager.

```bash
npm install @evanion/token
```

```bash
yarn add @evanion/token
```

```bash
pnpm add @evanion/token
```

## Construct a token instance

`createToken` checks its options once and returns a frozen object carrying
`generate` and `validate`. Build it at module scope, so the check runs once and
not on every request:

```ts twoslash file=libs/token/README.md region=construct

```

`createToken()` with no options takes the defaults, and the shop's pickup codes
need nothing else. `length` is 8 and counts the check character, so seven of
the eight characters are random. A hyphen splits the code into chunks of four,
which is why `value` comes back nine characters long.

## Mint a pickup code and check it with token

`generate` returns the code, and `validate` answers whether a code holds
together. Every call to `generate` draws different characters, so the example
checks what the round trip answers and not which characters came out:

```ts twoslash file=libs/token/README.md region=round-trip

```

`pickup.value` takes the shape `ORD-a4kp-9mxa`: the prefix `ORD`, a hyphen,
seven random characters and the check character, chunked in fours. Run it and
the seven characters differ each time. The shape does not.

The prefix sits outside the check, so `slice` cuts `ORD-` off before `validate`
reads the code. `a4kp-9mx8` is a fixed code whose check character is wrong.
`validate` refuses it, and the counter learns the code is bad without querying
the order table.

## Now that token mints a pickup code, configure it

[Generating and validating](/token/usage) sets `length`, `chunkSize` and
`separator`, and lists the three `reason` values `validate` returns.
