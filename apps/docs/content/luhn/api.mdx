# API reference

`@evanion/luhn` exports one factory, the default instance `Luhn` (also the name
of its type), two dictionaries, four other types and three error classes, one
heading each below. It runs on Node 20 or newer, as an ES module.

## `createLuhn`

<!-- reference @evanion/luhn#createLuhn example=pickup-dictionary -->

The example's 32 characters are the default 36 without `i`, `l`, `o` and `w`,
which are confused when read or heard. [`LuhnOptions`](#luhnoptions) lists the
two options and their defaults, and
[`InvalidDictionaryReason`](#invaliddictionaryreason) lists the five
constraints a dictionary can fail.

## `Luhn`

<!-- reference @evanion/luhn#Luhn example=frozen -->

`Luhn` names the interface in type space and the default instance in value
space, so `const luhn: Luhn = Luhn` compiles. Every instance `createLuhn`
returns carries the same members:

| Member             | What it is                                                                             |
| ------------------ | -------------------------------------------------------------------------------------- |
| `dictionary`       | the alphabet, as supplied                                                              |
| `n`                | the modulus: the number of code points in the dictionary                               |
| `caseInsensitive`  | whether input is folded to lowercase before lookup                                     |
| `uniformOverBytes` | whether `n` divides 256, so `byte % n` picks each character equally often              |
| `generate(input)`  | returns a [`GenerateResult`](#generateresult); throws `EmptyInputError`                |
| `validate(input)`  | returns a [`ValidateResult`](#validateresult) for a code ending in its check character |

## `LuhnOptions`

<!-- reference @evanion/luhn#LuhnOptions example=case-sensitivity -->

| Option            | Default                                                       |
| ----------------- | ------------------------------------------------------------- |
| `dictionary`      | `DEFAULT_DICTIONARY`                                          |
| `caseInsensitive` | `true` when `dictionary` is omitted, `false` when it is given |

`caseInsensitive: true` over a dictionary holding case pairs throws
`InvalidDictionaryError` with `reason: 'case-pairs'`.

## `GenerateResult`

<!-- reference @evanion/luhn#GenerateResult example=generate -->

`phrase` does not include `checksum`, because the check character did not
exist when the phrase was read.

## `ValidateResult`

<!-- reference @evanion/luhn#ValidateResult example=validate -->

`isValid` is `false` when `phrase` holds fewer than two code points. `phrase`
includes the check character, because that is what was validated, so the
payload without separators is `phrase.slice(0, -1)`.

## `InvalidDictionaryError`

<!-- reference @evanion/luhn#InvalidDictionaryError example=constraints -->

| Property     | What it holds                                                                           |
| ------------ | --------------------------------------------------------------------------------------- |
| `reason`     | the [`InvalidDictionaryReason`](#invaliddictionaryreason) that failed                   |
| `dictionary` | the dictionary as supplied                                                              |
| `offending`  | the repeated code points, or the case pairs joined as `'Aa'`; empty for the other three |

## `InvalidDictionaryReason`

<!-- reference @evanion/luhn#InvalidDictionaryReason -->

| `reason`       | What the dictionary must be                                           |
| -------------- | --------------------------------------------------------------------- |
| `not-a-string` | a string                                                              |
| `too-short`    | at least 2 code points long                                           |
| `odd-length`   | an even number of code points long                                    |
| `duplicate`    | free of repeated code points                                          |
| `case-pairs`   | free of case variants of one letter, when `caseInsensitive` is `true` |

An odd size is refused because a character at a doubled position contributes
`floor(2x / n) + (2x mod n)` for its index `x`, and over an odd `n` two indices
contribute the same amount, so a substitution between them goes uncaught.

## `EmptyInputError`

<!-- reference @evanion/luhn#EmptyInputError example=empty-input -->

`EmptyInputError` is the only error an instance's calls raise, and only
`generate` raises it. Every other constraint was settled when the instance was
built.
