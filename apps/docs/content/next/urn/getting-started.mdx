# Getting started

In this guide, you will create a `GameURN` class that can mint valid identifiers like `urn:game:brass-birmingham` and automatically refuse malformed ones.

## Prerequisites

To get started with `@evanion/urn`, you will need:

- **Node 20 or newer.** A CommonJS project loads the package through `require()` on Node 20.19, 22.12 or newer.
- **An ESM project**: If you're starting from scratch, run `npm init -y` and then `npm pkg set type=module`.

## Install @evanion/urn

Run the command for your preferred package manager:

```bash
npm install @evanion/urn
```

```bash
yarn add @evanion/urn
```

```bash
pnpm add @evanion/urn
```

## Define your namespace

The core of `@evanion/urn` is the **namespace class**. Instead of passing the namespace identifier (NID) as a string every time you call a function, you define a class that represents that namespace. The class then supplies the NID, so `GameURN.stringify('brass-birmingham')` needs no NID argument.

For a game shop, create a `GameURN` class that extends the base `URN` class and sets the `nid` to `'game'`, leaving the scheme and the separator at their defaults, `urn` and `:`. Save this as `game-urn.ts`:


The `stringify` method uses the `nid` and the provided slug to create the full URN. Before joining them, it validates the slug against the URN grammar. For example, a space is invalid in a Namespace Specific String (NSS), so the second call in the example throws an `InvalidError`. The example catches it and keeps its message, which names the part and the character, in `refused`. The `override` keyword is required under TypeScript's `noImplicitOverride` and optional without it.

## Run your code

The `// ->` comments in `game-urn.ts` show the two values `@evanion/urn` returns. To see it in your terminal, add `console.log(id, refused);` to the end of the file.

If you are using Node 22.18 or 23.6+, you can run the file directly:

```bash
node game-urn.ts
```

On older versions of Node, use `npx tsx game-urn.ts`. The terminal prints:
`urn:game:brass-birmingham NSS contains invalid character ' ' in 'brass birmingham'`.

## Handling multiple namespaces

A shop that sells games also takes orders, and keeps both kinds of `@evanion/urn` identifier in one list. [URNs from several namespaces](../namespaces) adds an `OrderURN` class and picks the game URNs out of a mixed list with `belongsToNamespace`.
