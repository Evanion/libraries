`urn:game:brass-birmingham`, and refuses a slug with a space in it.

## Before you install @evanion/urn

- Node 20 or newer.
- An ESM project. In an empty folder, `npm init -y` followed by
  `npm pkg set type=module` creates one. A CommonJS project needs Node 20.19,
  22.12 or newer, whose `require()` loads ES modules.
- Nothing else. The package has no runtime dependencies and no peer
  dependencies, and it ships its own types.

## Install @evanion/urn

Pick the line for your package manager.

```bash
npm install @evanion/urn
```

```bash
yarn add @evanion/urn
```

```bash
pnpm add @evanion/urn
```

## Mint a game URN with GameURN

`@evanion/urn` needs one piece of configuration, a namespace class: `GameURN`
extends `URN` and sets the static property `nid` to `'game'`. The scheme and
the separator keep their defaults, `urn` and `:`. Save this as `game-urn.ts`:

```ts twoslash file=libs/urn/README.md region=basic-usage

```

`stringify` reads the scheme and the NID off `GameURN` and joins them to the
slug. It checks each part against its grammar first. A space is outside the
grammar of the NSS, the part after the NID, so the second call throws an
`InvalidError` whose message names the part and the character. The `override`
keyword is required under TypeScript's `noImplicitOverride` and optional
without it.

## Run game-urn.ts

The `// ->` comments in `game-urn.ts` show the two values `@evanion/urn`
returns. Add `console.log(id, refused);` as the file's last line to print both,
then run the file. Node 22.18, 23.6 or newer runs a `.ts` file directly:

```bash
node game-urn.ts
```

On an older Node, run `npx tsx game-urn.ts` instead. Either command prints
`urn:game:brass-birmingham NSS contains invalid character ' ' in 'brass birmingham'`.

## Read a URN another service wrote

Your `game-urn.ts` imports `URN` from `@evanion/urn`, mints a game URN, and
refuses a malformed slug. [URNs from several namespaces](../namespaces) reads
the URNs arriving at the shop's `orders` service, where a game URN and an order
URN share one list.
