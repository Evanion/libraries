## Prerequisites

- **Node 20 or newer**, or any modern browser.
- **An ES module (ESM) project**. If you are using CommonJS, you will need Node 20.19, 22.12 or newer to load ES modules via `require()`.
- **Dependencies**: None. The package has no peer or runtime dependencies.

## Install luhn

Run the command for your preferred package manager:

```bash
npm install @evanion/luhn
```

## Using the Default Instance

The most common use case is the default 36-character dictionary (0-9, a-z). For this, you don't need any configuration—just import the `Luhn` instance.

```ts
import { Luhn } from '@evanion/luhn';
```

## Print an Order Code with a Check Character

`@evanion/luhn` computes the check character but leaves the final string formatting to you. 

Imagine your database holds an **order number** like `order-2026-0042`. You want to print an **order code** on the receipt—the order number plus a check character—so that it can be validated locally.

In this example, `Luhn.generate` returns the check character as `checksum`. We append it with a hyphen for readability. When a customer reads the code back, `Luhn.validate` ignores the hyphen and other non-dictionary characters (reading only the **phrase**), allowing it to verify the code regardless of how it was formatted.

If a customer reads `order-2026-0042-l` as `order-2026-0042-1`, `validate` will immediately return `isValid: false`. Your system can then ask the customer to repeat the code before ever querying the database for an order that doesn't exist.
