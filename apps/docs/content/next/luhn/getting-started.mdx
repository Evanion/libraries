## Prerequisites

`@evanion/luhn` needs only a modern JavaScript runtime:

- **Node 20 or newer**, or any modern browser.
- **An ES module (ESM) project**. If you are using CommonJS, you will need Node 20.19, 22.12 or newer to load ES modules via `require()`. An older `require()` fails with `ERR_REQUIRE_ESM`.
- **Dependencies**: None. The package has no peer or runtime dependencies.

## Install luhn

Run the command for your preferred package manager:

```bash
npm install @evanion/luhn
```

```bash
yarn add @evanion/luhn
```

```bash
pnpm add @evanion/luhn
```

## Using the Default Instance

The most common use case for `@evanion/luhn` is the default 36-character dictionary (0-9, a-z). For this, you don't need any configuration: `import { Luhn } from '@evanion/luhn'` gives you the default instance, and the next section runs it.

## Print an Order Code with a Check Character

`@evanion/luhn` computes the check character but leaves the final string formatting to you.

In this example, `Luhn.generate` returns the check character as `checksum`, and `orderCode` appends it after a hyphen for readability. When a customer reads the code back, `Luhn.validate` ignores the hyphen and other non-dictionary characters (reading only the [phrase](../#how-the-luhn-sum-works)), allowing it to verify the code regardless of how it was formatted.

If a customer reads `order-2026-0042-l` as `order-2026-0042-1`, `validate` immediately returns `isValid: false`. Your system can then ask the customer to repeat the code before ever querying the database for an order that doesn't exist.
