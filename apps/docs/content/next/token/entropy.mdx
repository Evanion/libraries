## Read entropyBits off an instance

`length` counts the check character, so a token code carries
`(length - 1) * log2(n)` random bits, where `n` is the dictionary's size.
`entropyBits` reports the figure:

```ts twoslash file=libs/token/README.md region=entropy

```

The default `length` of 8 and the default 32-character dictionary give 35 bits.
A `length` of 12 gives 55. A `length` of 13 gives 60. The example passes
`chunkSize: 13` because 4 does not divide 13, which [Code shape](../shape)
refuses.

## How many codes 35 bits carries before two collide

35 bits, the entropy of a default token code, is 34,359,738,368 values, and two
codes collide long before they run out. With a unique index on the orders table,
a collision costs one redraw, and the chance that the next insert conflicts
decides `length`. The table below counts something else, when the first redraw
arrives:

| Issued codes | Chance at least two collide, at 35 bits |
| ------------ | --------------------------------------- |
| 10,000       | about 0.15%                             |
| 100,000      | about 14%                               |
| 218,000      | about 50%                               |
| 1,000,000    | effectively certain                     |

The table follows the birthday bound: the 50% point is roughly
`1.18 × sqrt(2^bits)`. Five more characters add 25 more bits, which moves the
50% point to about 1.3 billion:

| `length` | bits | 50% collision at |
| -------- | ---- | ---------------- |
| 6        | 25   | 6,800            |
| 8        | 35   | 218,000          |
| 10       | 45   | 7,000,000        |
| 13       | 60   | 1,300,000,000    |

## Keep pickup codes unique with a unique index

Token's `generate` never retries and never checks for collisions, because the
package does not know which codes you have issued. The orders table does. Put a
unique index on `body` and draw again when the insert conflicts:

```ts twoslash file=libs/token/README.md region=issue

```

`issued` stands in for the unique index, and `insertPickupCode` returns `false`
where a database raises a unique violation. In your code, catch that violation
and nothing else. `issuePickupCode` draws up to five times and then throws, so a
table that has run out of codes raises an error.

## Size length for the codes you will issue

Size a token code's `length` against the chance that the next insert conflicts,
which is the codes already issued divided by `2^bits`. At 218,000 codes and 35
bits that chance is 1 in 158,000.

Keep it below 1 in 1,000 at the volume you expect in three years. Then at most
one insert in 1,000 redraws, and five conflicts in a row, which make the
`issuePickupCode` example above throw, happen once in 10¹⁵ inserts. At 35 bits
the chance reaches 1 in 1,000 at about 34 million codes.

## A pickup code does not resist guessing

A default token code's 35 bits are not enough to stop an attacker enumerating
codes. If a code is a capability, such as a password reset link or a download
link, where knowing the string grants access, `@evanion/token` is the wrong
package. Use a 128-bit random value and do not make it readable, because nobody
types it.

A token code is one a person handles: a pickup code, a support ticket. It is
looked up, and what it defends against is a transcription error. The shop's
counter hands an order over after it checks the customer's name as well as the
pickup code.

If a readable code does gate something, such as a gift card's balance,
rate-limit the lookup and bind it to a second factor the guesser does not have,
such as the email address the code was sent to.

## Why a token code cannot be shorter

Two changes would carry the same entropy in fewer characters, and token makes
neither:

- A 64-character dictionary, at 6 bits a character against 5. `createToken`
  refuses uppercase, so its extra 32 characters would have to be punctuation or
  non-ASCII letters, which a person struggles to read aloud or type.
  [The alphabet](../alphabet) says why the default stops at 32.
- No check character. `length: 8` with no check character would carry 40 bits
  against 35, and a mistyped code would then cost a database lookup and a "not
  found". `createToken` has no option to drop it.
