## Before you install compose

- React 18 or 19, the only dependency `@evanion/compose` has.
- `react-dom`, which renders this page's example.
- Node 20 or newer.
- An ESM project. A CommonJS project needs a Node whose `require()` loads ES
  modules: 20.19 or later on Node 20, or 22.12 or later. An older `require()`
  fails with `ERR_REQUIRE_ESM`.
- (Optional) TypeScript 5.0 or newer, for the compile error on each entry. The
  component runs without it.

## Install compose

Pick the line for your package manager.

```bash
npm install @evanion/compose
```

```bash
yarn add @evanion/compose
```

```bash
pnpm add @evanion/compose
```

## Compose the shop's context providers

`ComposeProvider`, from `@evanion/compose`, nests context providers the way the
[Overview](../#how-a-provider-array-becomes-a-tree) nested `div`s, first entry
outermost. The shop's root holds a cart, a theme and a currency, each built on
`createContext`. `Shop` passes the three to `ComposeProvider`, and `Basket`
reads each value with `useContext`. The file imports `ComposeProvider` and
`provider` from `@evanion/compose` and `* as React` from `react`.
`renderToStaticMarkup`, from `react-dom/server`, turns the tree into the HTML
string `markup`, which only this example needs:

```tsx twoslash file=libs/compose/README.md region=first-shop

```

`CartProvider` is a [bare component](../#four-words-for-a-provider-array) and
the other two are `provider()` tuples. The last entry gets `Shop`'s own
children.

`markup` is `Basket`'s paragraph and nothing else. The Overview's providers each
rendered a `div`, and a context provider renders no element of its own, so
`dark` and `SEK` in the markup are the values the providers above `Basket`
hold. In a browser, the Components tab of React
DevTools shows the order: each provider sits inside the one before it in the
array.

## Put Shop at your app's root

`Shop`, the component that composes the providers with `@evanion/compose`,
goes where your nested providers sit today, around your routes. In a Next.js
App Router app, the file that calls `createContext` is client code. Start it
with `'use client'`, define the providers and `Shop` there, and render
`<Shop>{children}</Shop>` from `app/layout.tsx`. `ComposeProvider` itself needs
no directive.
