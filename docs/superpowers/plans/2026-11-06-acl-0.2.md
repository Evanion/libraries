# acl 0.2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Nested field paths, `validateAll`, `explain` and `canEach` in `@evanion/acl`, released together as 0.2.0.

**Architecture:** A path codec module parses and formats escaped dotted paths. `decideFields` walks the object and the write along a trie built from the rules, and `pickAllowedFields` rebuilds the allowed tree from the decision. Validation becomes one collector that `validateMatrix` throws from and `validateAll` returns. `explain` and `canEach` sit on `Access`, next to `can` and `canMany`, and reuse `decideResolved`.

**Tech Stack:** TypeScript, vitest (including `expectTypeOf` in `*.test-d.ts`), Nx (`npx nx ... --skip-nx-cache --parallel=2`), Nextra docs with twoslash fences.

**Spec:** `docs/superpowers/specs/2026-11-03-acl-0.2-design.md`. Read it before any task. Section numbers below ("Spec P1 › Arrays") point into it.

## Global Constraints

- Every policy that names no dotted entry decides exactly as on main today: same map keys, states and reasons. The one exception is a flat key containing `.` or `\`, whose map key becomes escaped.
- A decision never throws, for any subject, object or write.
- `__proto__`, `*` and `!name` never key a decision map at any depth, and never appear in any object that `pickAllowedFields` builds.
- Each task is its own branch and PR from current `origin/main`. Tasks 1–3 merge in order. Until Task 3 lands, construction keeps refusing dotted and backslash entries, so main never accepts a path the engine cannot enforce.
- Comments describe the code, never its history ("used to", "previously", "this fixes").
- Docs prose goes through `node .git/governor-tools/gemma.mjs <draft> --ask "<instruction>"`. Keep Gemma's text and fix only statements that are false about the library. Edit `apps/docs/content/next` only, never cut versions.
- Every new export gets a `## \`name\``section on`apps/docs/content/next/acl/api.mdx`with a`<!-- reference @evanion/acl#name ... -->`line (G10). Every callable export gets a`describe('name')`in acl's tests (G11). Examples go in`libs/acl/docs/examples.md`regions as`ts @import.meta.vitest` fences.
- Verify each task with `npx nx run-many -t lint test build typecheck -p acl react-acl docs --skip-nx-cache --parallel=2`, `npx nx test repo-checks --skip-nx-cache` and `npx prettier --check <changed files>`. All must exit 0.
- Commits are conventional and end with the session's Co-Authored-By trailer. Never `--no-verify`, force push or merge.

## Review Focus

1. A nested object from `JSON.parse` carrying an own `__proto__` key, on the read object and on the write. Expected: never a map key, never in a picked object, and no prototype change on anything built. Test in Task 2.
2. A nested property defined as a getter (an ORM row, a lazy proxy). Reading it could throw or answer differently each time. Expected: the walk does not invoke getters, and an accessor property where a rule descends is `not-traversable`. Test in Task 2.
3. A self-referencing object (`a.self = a`) under a rule that descends through `self` more than the data has distinct levels. Expected: terminates, with `not-traversable` at the repeat. Test in Task 2.
4. A sparse array or an array mixing plain objects with primitives or `Date`s under `!lines.cost`. Expected: the whole array is `denied`/`not-traversable`, and pick never drops single elements. Test in Task 2.
5. A thrown error from `validateMatrix` on a document that has several faults. Expected: the same class and message main throws today for the first fault, so existing callers' `instanceof` checks and messages hold. Test in Task 6.

**Interfaces:**

- Produces (module-internal, not exported from `index.ts`):
  - `parsePath(path: string): readonly string[] | undefined`. It returns the segments, or `undefined` for a malformed path.
  - `formatPath(segments: readonly string[]): string`. This is the inverse: it escapes `.` and `\` in each segment and joins with `.`.
  - `pathFault(path: string): string | undefined`. It returns a sentence for the error detail, or `undefined` when the path is valid as a field-rule path.
