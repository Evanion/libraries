# feature 0.2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Context paths, instant fields with relative boundaries, `exists`/`not-exists`, and the publisher helpers in `@evanion/feature`, released as 0.2.0.

**Architecture:** A path module in `libs/feature` parses paths and reads them from a context through own data properties. Every place the engine reads a context field by name calls it. New condition shapes extend `types.ts`, `evaluateCondition` and `validate.ts`. Publisher helpers live in a new `requirements.ts`.

**Tech Stack:** TypeScript, vitest, Nx (`npx nx ... --skip-nx-cache --parallel=2`), Nextra docs with twoslash fences.

**Spec:** `docs/superpowers/specs/2026-11-07-feature-0.2-conditions-design.md`. Read it before any task.

## Global Constraints

- A document that uses no dotted name and none of the new constructs decides exactly as on main: same decisions, reasons, rule ids and plan output.
- Evaluation never throws on context data, including getters, proxies, cycles and non-plain objects.
- Paths read own data properties of plain objects only (prototype `Object.prototype` or `null`), and getters are never invoked.
- Each task is its own branch and PR from current `origin/main`.
- Comments describe the code, never its history.
- Docs prose goes through `node .git/governor-tools/gemma.mjs <draft> --ask "Rewrite this in your voice. Keep every fact."`. Keep Gemma's text and fix only false statements. Edit only `apps/docs/content/next/feature`.
- New exports get a `## \`name\``section on the feature API page with a reference line (G10), and a`describe('name')`in tests (G11).`nx test repo-checks` names what is missing.
- Verify every task with these three commands, and read each exit status:
  - `npx nx run-many -t lint test build typecheck -p feature react-feature docs --skip-nx-cache --parallel=2`
  - `npx nx test repo-checks --skip-nx-cache`
  - `npx prettier --check <changed files>`
- Commit subjects backtick camelCase names. Commits end with the session's Co-Authored-By trailer. Never `--no-verify`, force push or merge.

## Review Focus

1. A context with a getter, a class instance or a revoked proxy at a path segment. Expected: the field is absent, the condition is false, and nothing throws. Test in Task 1.
2. A flat context key that a path also spells (`{ 'subject.id': 'x', subject: { id: 'y' } }`). Expected: `subject.id` reads `'y'`, and `subject\.id` reads `'x'`. Test in Task 2.
3. `not-exists` over a path whose parent is an array or `null`. Expected: it holds, because the field is absent. Test in Task 2.
4. `{ fromNow }` evaluated when `now` is missing or does not parse. Expected: false, never "now = epoch 0". Test in Task 3.
5. `requirements()` on a document using a non-`now` `before`/`after` or a dotted name. Expected: `version: '0.2.0'`. Portcullis blocks publishing on this value. Test in Task 6.

### Task 1: Path module

**Files:**

- Create: `libs/feature/src/lib/field-path.ts`, `libs/feature/src/lib/field-path.spec.ts`

**Interfaces:**

- Produces:
  - `parsePath(path: string): readonly string[] | undefined`
  - `formatPath(segments: readonly string[]): string`
  - `escapeField(name: string): string`, which is `formatPath([name])`
  - `pathFault(path: string): string | undefined`. It refuses everything acl's `pathFault` refuses, plus `constructor` and `prototype` segments and more than 32 segments.
  - `readPath(bag: unknown, path: string): { present: boolean; value?: unknown }`. `'now'` reads the top-level `now`. A malformed path is absent.

- [ ] **Step 1: Write the failing tests** in `describe('parsePath')`, `describe('escapeField')` and `describe('readPath')`:
  - Copy acl's `field-path.test.ts` cases verbatim (`libs/acl/src/field-path.test.ts`).
  - Add `pathFault('a.constructor')` and `pathFault('a.prototype')` as non-undefined, and a 33-segment path refused.
  - `escapeField('a.b')` → `'a\\.b'`.
  - `readPath({ subject: { id: 'u' } }, 'subject.id')` → `{ present: true, value: 'u' }`.
  - A missing segment is absent. `{ subject: null }` is absent. `{ subject: ['x'] }` with `subject.0` is absent. A `Date`, a class instance or a `Map` parent is absent.
  - A getter at a segment is absent and never called (`vi.fn`). A revoked proxy at a segment is absent and does not throw.
  - A value of `undefined` reads as `{ present: true, value: undefined }`. Task 2 decides what `undefined` means.
  - `readPath({ 'a.b': 1 }, 'a\\.b')` → present 1.

- [ ] **Step 2: Run** `npx vitest run --root libs/feature src/lib/field-path.spec.ts`. Expected: FAIL.

- [ ] **Step 3: Implement.** Copy the codec from `libs/acl/src/field-path.ts` rather than importing it, so neither package depends on the other. Read each level with `Object.getOwnPropertyDescriptor` inside a try. Track visited objects so a cycle is absent.

**Interfaces:**

- Produces: `durationMs(text)` parses a signed ISO 8601 duration restricted to W/D/H/M/S, and returns `undefined` otherwise.

- [ ] **Step 1: Write the failing tests:**

  - `value: { fromNow: '-P30D' }` with `now` `2026-11-07T00:00:00Z`: `createdAt` `2026-10-20` → true, `2026-10-01` → false.

  - `durationMs`: `'-P30D'` = −30 × 86,400,000. `'PT12H'`, `'-P2W'`, `'-PT90M'` and `'PT1.5S'` parse. Decide whether fractional seconds parse and test the choice. `'P1M'`, `'P1Y'`, `'30D'`, `''` and `'P'` → undefined.

    - `field: 'now'` with `{ fromNow }` → an issue.
    - A non-`now` `before` under a schema declaring the field `string` → an issue. Declared `instant?` → ok.
  - Every existing `now` window test passes unchanged.
  - `ruleId` is stable for a `{ fromNow }` condition and distinct from an absolute one.
